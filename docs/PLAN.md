# docs/PLAN.md — fayna-ai-kiosk

## Фаза 0 — Extract & sanitize ✅

Витяг голосового кіоска з внутрішнього проєкту, знеособлення (реальні записи
розмов, справжнє меню/контакти клієнта виключені), приведення до REPO_STANDARD,
fresh git history без AI-підписів. (Процедура Project Sunset.)

## Фаза 1 — Senior-grade pass ✅

- Пакетна структура `src` (config/nlp/stt/tts/kiosk) замість монолітного скрипта.
- Детермінований keyword-NLP (15+ інтентів) — нуль галюцинацій, без LLM.
- Safety-critical правила (алергени, вікові обмеження, заборонені теми) винесені
  в `src/config/settings.py`.
- `pytest` юніт-тести без аудіо-заліза; CI (ruff + gitleaks + mypy + pytest).

## Фаза 2 — Demo hardening

- End-to-end smoke-прогін на демо-даних `data/knowledge.json` (STT→NLP→TTS) на
  реальному залізі (мікрофон + динамік) у CI-сумісному скрипті або окремому
  manual-тесті.
- README-скріншот/GIF демо-сесії кіоска.

## Фаза 3 — Покриття тестами

- Розширення юніт-тестів на всі 15+ інтентів NLP-процесора.
- Тести `settings.py` (алергени, вікові обмеження, заборонені теми).
- Coverage-репорт, ціль ≥70% критичного шляху (NLP + config).

## Checkpoints

- Кінець Фази 1 → готове до публічного портфоліо-показу.
- Кінець Фази 3 → NLP-шлях покритий тестами без живого аудіо-заліза в CI.
